- **File:** `docker-compose.prod.yml` (~:40-43, redis service healthcheck)
- **Trigger:** `test: ["CMD", "redis-cli", "-a", "${REDIS_PASSWORD:?set REDIS_PASSWORD in .env}", "ping"]`
- **What:** `REDIS_PASSWORD` is passed via `-a` on the process command line, exposing it in the container's `/proc/<pid>/cmdline` (readable by host root / anyone with `docker exec` or docker-socket access) every 5s for the container's lifetime. - **Impact:** honestly bounded — the same password is already in the container's environment (`REDIS_URL` in api/worker/migrate) and visible via `docker inspect` to the same privilege level, so the marginal exposure is near-zero. Filed as LOW for hygiene; not a real privilege escalation.
