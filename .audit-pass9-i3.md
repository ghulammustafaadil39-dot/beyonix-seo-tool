## 2. NEW findings

### NEW LOW #1 — LOW — `reportsV2Api.pdfUrl`/`htmlUrl` interpolate `reportId` raw (H3-L-2 fix missed them)
- **Files:** `frontend/lib/api.ts:1580-1581`:
  ```ts
  pdfUrl: (reportId: string) => `${BASE_URL}/api/v1/reports/${reportId}/pdf`,
  htmlUrl: (reportId: string) => `${BASE_URL}/api/v1/reports/${reportId}/html`,
  ```
- **Trigger:** live in `components/tabs/ReportsV2Panel.tsx:258-259` as `<a href={reportsV2Api.pdfUrl(selectedId)}>` ("Download PDF") and `<a href={reportsV2Api.htmlUrl(selectedId)} target="_blank" rel="noreferrer">` ("View HTML"). `selectedId` is the selected report's id from the backend report list; a `reportId` containing `/`, `?`, `#`, or `%2f` reshapes the request path (e.g. `/reports/x/pdf` → a different route entirely) instead of 404ing.
- **Impact:** LOW — same rationale as H3-L-2: self-only (a user reshapes only their own request), React escapes the attribute value so no XSS, backend route expects a UUID and must reject anyway. Defense-in-depth inconsistency: the pass#8 fix established the pattern (`encodeURIComponent`) and applied it to five builders, but missed these two because H3's census said "the five."
- **Fix:** wrap both in `encodeURIComponent(reportId)`, exactly like the five fixed builders.
- **Duplicate check:** grepped all `.audit-pass{1..8}-*.md` for `pdfUrl`, `htmlUrl`, `reportsV2Api`. Only hit: pass1-a3 §"Download/export URLs … are plain links — cookie auth applies, no tokens embedded in URLs" — a token-leakage observation, not the path-injection-encoding class H3-L-2 filed. No prior pass filed the missing encoding. **NEW.**

**Residual note (not filed):** dozens of `api()`-path interpolations (e.g. `reportsV2Api.build`, `compare`, `createShare`, `listShares`, `auditsV2Api.groups/diff`) also interpolate IDs raw — but those go through `fetch` with relative URLs, never into DOM anchors, so they sit outside the H3-L-2 class. Flagging so the parent can decide whether to broaden the encoding rule beyond download-URL hrefs; not filed to avoid duplicate inflation.
