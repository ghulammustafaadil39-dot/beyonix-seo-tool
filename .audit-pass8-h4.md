### NEW LOW-1 — stale `postcss: ^8.4.35` in `frontend/package.json` devDependencies
**File:** `frontend/package.json:14`.
The manifest declares `"postcss": "^8.5.29"` in `dependencies` (line 4) but still
carries `"postcss": "^8.4.35"` in `devDependencies` (line 14) — a leftover from the Wave 0
baseline (`cc622a6`), predating the ^8.5.29 pin added for E5-M-1. npm resolves to 8.5.29
(confirmed: single `node_modules/postcss` at 8.5.29 in the lockfile), so there is **no
vulnerability** — this is a manifest self-contradiction / hygiene wart that could confuse
a future `npm install` in a lockfile-less context or an auditor eyeballing declared ranges.
**Fix:** align the devDep to `^8.5.29` or delete it (dependencies already pin postcss).
