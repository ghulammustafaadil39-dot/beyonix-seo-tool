## 2. Hunt results (adversarial sweeps, no new findings)

Checked and found sound — no filing:
- **Metering races:** `reserveUsage` — single tx, per-tenant `pg_advisory_xact_lock`, check+insert atomic; `commitUsage` — single-statement CTE, clamps to reserved amount (`LEAST(COALESCE($2, units), units)`), rejects expired holds (410). `cancelUsage` idempotent. Alert hooks fire post-commit, first-writer-wins. `withUsageReservation` cancels on work-throw.
- **Scheduler enrollment:** both spend queries filter `suspended_at IS NULL`, `read_only = FALSE`, and trial liveness — suspended / read-only / trial-expired tenants are excluded. `stuck-audit-reaper` only touches `queued` rows older than 2h. Leader election: `SET NX` per tick + Lua compare-and-extend heartbeat; double-tick impossible even with N workers.
- **Worker job duplication/loss:** per-tick idempotency keys as BullMQ jobIds; fairness deferral uses `DelayedError` (never returns normally after `moveToDelayed`); terminal failures → dead-letter table; stalled jobs retried (`maxStalledCount: 3`); graceful shutdown drains in-flight work. Webhook deliveries: atomic conditional-claim UPDATE + 10-min stale-claim reaper.
- **Crypto:** AES-256-GCM, per-encrypt random IV, kid versioning, legacy `enc:` tried against all keys post-rotation (B2-M6), `plain:` refused outside dev/test, production refuses to boot without a key. No key-logging; `kid` from stored data is only a map lookup.
- **Rate limiters:** Lua atomic INCR+TTL; limiter Redis is the bounded client (2s per-command ceiling, fail-closed 429 on outage); `tenantRateLimit` wired AFTER `requireVerifiedEmail` on all expensive routes checked (content ×4, geo, account invites). Queue-level limiter fail-closed. No bypass found: scheduler's `rateLimit: false` is the intended system-caller path.
- **Caching:** all shared caches (`keyword_metrics_cache`, `serp_cache`, `serp_snapshots`, `pagespeed_cache`) keyed by public data (keyword/location/device), never by tenant; per-tenant values (own-domain position) computed at read time. `source_provider` tracked so mock rows are honestly labeled. Flight lock is a coalescing optimization with safe degradation (no coalescing on Redis outage, bounded 60s TTL). Idempotency keys are `(tenant_id, key)`-scoped with atomic claim/reap and 422 on body-hash mismatch.
- **Migration ordering/idempotency:** every migration in 001–048 uses `IF NOT EXISTS` / `ON CONFLICT` / conditional guards; each file runs in its own tx and is recorded only on success.
